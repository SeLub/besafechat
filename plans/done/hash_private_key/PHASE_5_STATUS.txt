================================================================================
WHAT GETS TESTED
================================================================================

FUNCTIONAL TESTING
- Hash-based encryption works correctly
- Messages encrypt/decrypt properly
- Session hash persists during login
- Hash cleared on logout
- Database isolation per user
- Message history preserved

SECURITY TESTING
- Private key destroyed after auth
- User B cannot decrypt User A's messages
- Database isolation enforced
- Cross-user access prevented
- No plaintext keys in memory

PERFORMANCE TESTING
- Hash computation: <10ms
- Encryption operation: <50ms
- Decryption operation: <50ms
- Database initialization: <150ms
- Database switching: <500ms

MANUAL TESTING SCENARIOS
================================================================================

SCENARIO 1: Single User Encryption Flow (15 min)
- Create account, send message, refresh, logout, re-login
- Validates: Encryption works, persists, recovers

SCENARIO 2: Cross-User Database Isolation (20 min)
- User A sends message, User B tries to decrypt
- Validates: Cross-user isolation, data protection

SCENARIO 3: Multiple Login Cycles (15 min)
- Create account, logout/login multiple times with different users
- Validates: Deterministic database naming, message persistence

SCENARIO 4: Performance Under Load (20 min)
- Measure encryption/decryption performance
- Validates: All operations meet timing targets

SCENARIO 5: Error Handling & Edge Cases (20 min)
- Test encryption without login, corrupted data, etc.
- Validates: Graceful error handling, no crashes
