# Детальный план реализации автоматического создания профиля при создании обработчика

---

## 🎯 Цель

Гарантировать автоматическое создание профиля (`Profile`), когда создается обработчик (`Handle`), используя следующие подходы:

1. **Использовать транзакцию для одновременного создания `Handle` и `Profile`**. ✅ РЕАЛИЗОВАНО
2. **Использовать lifecycle-хук в `Handle`-сущности** для автоматического создания `Profile`. ⚠️ НЕ ТРЕБУЕТСЯ

### 📁 Файлы, которые нужно изменить:

- `handle.service.ts` — реализовать логику транзакции.
- `handle.controller.ts` — если требуется, изменить обработку запроса.

### 📌 Что нужно сделать:

#### ✅ В `handle.service.ts`:

- Реализовать логику создания `Handle` и `Profile` в одной транзакции.
- Использовать ORM (например, TypeORM) для создания транзакции.
- Обработать ошибки и откатить транзакцию, если `Profile` не может быть создан.

#### ✅ В `handle.controller.ts`:

- Убедиться, что контроллер вызывает правильный метод в `handle.service.ts`.
- Не вносить изменения, если логика создания `Handle` и `Profile` полностью перенесена в `handle.service.ts`.

### 📌 Что нужно сделать:

#### ✅ В `handle.entity.ts`:

- Убедиться, что `Profile` создается **только если это `Handle` типа 'account'** (или другое условие, если нужно).
